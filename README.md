# Technical Knowledge Bias and Accuracy Analyzer

An AI-powered system that analyzes technical content, extracts claims, evaluates accuracy, detects bias, and generates neutral explanations.

## Project Overview

The Technical Knowledge Bias and Accuracy Analyzer allows users to submit:

- URLs
- Technical text
- Documents

The system processes the information through an AI workflow to:

1. Extract technical claims
2. Classify claims
3. Retrieve supporting evidence
4. Evaluate accuracy
5. Detect possible bias
6. Generate a neutral explanation
7. Produce a structured report
